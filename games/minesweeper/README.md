# Minesweeper

Retro Minesweeper in the browser.

## Run

Open `index.html` in your browser.

If you need a local server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/games/minesweeper/`.

## Controls

- Left click: reveal
- Right click: flag
- Double click on a revealed number: chord reveal
